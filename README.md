# คู่มือโปรเจกต์: IoT Smart Gas Detector (ระบบตรวจจับแก๊สอัจฉริยะ)

โปรเจกต์นี้คือระบบตรวจจับแก๊สและควันไฟ โดยใช้บอร์ด ESP8266 (NodeMCU) ร่วมกับเซนเซอร์ MQ-2 พร้อมระบบระบายอากาศอัตโนมัติ (Fan Control) และแจ้งเตือนผ่านแอปพลิเคชัน Blynk

---

## 1. อุปกรณ์ที่ใช้ (Hardware Requirements)

1.  **Microcontroller:** ESP8266 NodeMCU V2/V3
2.  **Sensor:** MQ-2 Gas/Smoke Sensor
3.  **Display:** LCD 16x2 + I2C Interface Module
4.  **Actuators:**
    * Relay Module 1 Channel (5V)
    * พัดลมระบายอากาศ (12V Fan)
    * Active Buzzer (3V-5V)
    * LED (สีแดง)
5.  **Power Supply:**
    * Adapter 5V 2A (สำหรับเลี้ยงบอร์ดและเซนเซอร์)
    * Adapter 12V (สำหรับเลี้ยงพัดลม แยกต่างหาก)

---

## 2. การต่อวงจร (Wiring Diagram)

### 2.1 ส่วนควบคุม (Control Side)
ตารางการต่อสายจากอุปกรณ์ต่างๆ เข้าสู่บอร์ด ESP8266 NodeMCU:

| อุปกรณ์ (Device) | ขาอุปกรณ์ (Pin) | ขา ESP8266 (NodeMCU) | หมายเหตุ |
| :--- | :--- | :--- | :--- |
| **MQ-2 Sensor** | VCC | **Vin** (5V) | ห้ามใช้ 3.3V เพราะฮีตเตอร์จะไม่ร้อน |
| | GND | **GND** | |
| | A0 (Analog) | **A0** | อ่านค่าความเข้มข้นแก๊ส (0-1024) |
| **LCD I2C** | VCC | **Vin** (5V) | จอต้องการไฟ 5V เพื่อความสว่าง |
| | GND | **GND** | |
| | SDA | **D2** (GPIO4) | ขาสัญญาณ I2C Data |
| | SCL | **D1** (GPIO5) | ขาสัญญาณ I2C Clock |
| **LED** | Anode (+) | **D5** (GPIO14) | ขาบวก (ขายาว) |
| | Cathode (-) | **GND** | ขาลบ (ขาสั้น) |
| **Buzzer** | VCC | **3V3** | |
| | GND | **GND** | |
| | I/O (Signal) | **D6** (GPIO12) | ทำงานแบบ Active LOW |
| **Relay Module** | VCC | **Vin** (5V) | **สำคัญ:** ต้องใช้ไฟ 5V เท่านั้น |
| | GND | **GND** | |
| | IN (Signal) | **D7** (GPIO13) | ใช้เทคนิค Input Mode ตัดวงจร |

### 2.2 ส่วนพัดลม (Fan Power Side)
การต่อพัดลม 12V ผ่าน Relay (ทำหน้าที่เป็นสวิตช์ตัดต่อไฟ):

1.  **ไฟบวก (12V+):** จาก Adapter 12V -> เข้าช่อง **COM** ของ Relay
2.  **ไฟออกจาก Relay:** จากช่อง **NO (Normally Open)** ของ Relay -> ไปเข้าขั้วบวกของพัดลม
3.  **ไฟลบ (GND):** จากพัดลม -> ต่อตรงเข้ากับขั้วลบของ Adapter 12V

## 3. หลักการทำงานของระบบ (System Operation)

ระบบทำงานเป็น Loop วนซ้ำทุกๆ 1 วินาที โดยมีลำดับขั้นตอนดังนี้:

### 3.1 การอ่านค่า (Monitoring)
* บอร์ดอ่านค่าจากเซนเซอร์ MQ-2 ผ่านขา **A0**
* ค่าที่ได้จะเป็นตัวเลขระหว่าง **0 ถึง 1024**
* ส่งค่าขึ้นแสดงผลบน **Blynk (Widget Gauge/Graph)** ผ่าน Virtual Pin **V0**
* แสดงค่า Real-time บนหน้าจอ **LCD บรรทัดที่ 1**

### 3.2 การตรวจสอบเงื่อนไข (Logic Control)
ระบบจะเปรียบเทียบค่าที่อ่านได้กับค่าวิกฤต (**Threshold = 600**)

#### **กรณีที่ 1: ตรวจพบแก๊ส/ควัน (ค่า > 600)**
* **สถานะ:** DANGER (อันตราย)
* **LED:** ติดสว่าง (แจ้งเตือนด้วยแสง)
* **Buzzer:** ส่งเสียงร้อง (แจ้งเตือนด้วยเสียง)
* **Relay (พัดลม):** ทำงานทันที เพื่อดูดควันออก
* **Blynk:** ส่ง Notification เข้ามือถือว่า *"Warning! Gas Leak Detected!"*
* **LCD บรรทัดที่ 2:** แสดงข้อความ `"STATUS: DANGER!"`
* **ตัวนับเวลา (Timer):** ถูกรีเซ็ตไปที่ 10 วินาที เพื่อเตรียมหน่วงเวลา

#### **กรณีที่ 2: ค่าลดลงสู่ระดับปกติ (ค่า <= 600)**
* **LED:** ดับทันที
* **Buzzer:** หยุดร้องทันที
* **ระบบหน่วงเวลาพัดลม (Smart Fan Delay):**
    * เมื่อค่าลดลงแล้ว พัดลมจะ **ยังไม่ดับทันที**
    * ระบบจะสั่งให้พัดลมหมุนต่ออีก **10 วินาที** เพื่อระบายควันที่ตกค้างให้หมด
    * **LCD บรรทัดที่ 2:** แสดงข้อความ `"Clearing Smoke.."`
    * เมื่อครบ 10 วินาที -> พัดลมจะหยุดหมุน และจอแสดง `"STATUS: Safe"`

## 4. ปัญหาและเทคนิคการแก้ปัญหา (Troubleshooting & Tips)

### 4.1 จอ LCD วูบ หรือดับเมื่อพัดลมทำงาน
* **สาเหตุ:** กระแสไฟจากพอร์ต USB คอมพิวเตอร์ไม่พอจ่าย (MQ-2 กินไฟเยอะ + Relay กินไฟ + WiFi กินไฟ)
* **วิธีแก้:** เปลี่ยนไปเสียบไฟจาก **Adapter USB (หัวชาร์จมือถือ)** ขนาด 5V 2A ขึ้นไป

### 4.2 Relay เปิดแล้วไม่ยอมปิด (ไฟค้าง)
* **สาเหตุ:** แรงดันไฟ Logic ของ ESP8266 (3.3V) ไม่สามารถเอาชนะไฟเลี้ยง Relay (5V) ได้เด็ดขาด
* **วิธีแก้ในโค้ด:**
    * ตอนเปิด: ใช้ `pinMode(OUTPUT)` และ `digitalWrite(LOW)`
    * ตอนปิด: ใช้ `pinMode(INPUT)` เพื่อตัดขาสัญญาณให้ลอย (Floating) ทำให้ Relay ตัดวงจรได้สมบูรณ์

### 4.3 เสียง Buzzer ดังเบา หรือสลับการทำงาน
* **สาเหตุ:** โมดูล Buzzer และ Relay ส่วนใหญ่ทำงานแบบ **Active LOW** (ส่ง 0 ทำงาน / ส่ง 1 หยุด)
* **วิธีแก้:** เขียนโค้ดกลับตรรกะ (Invert Logic)
    * ให้ทำงาน = สั่ง `LOW`
    * ให้หยุด = สั่ง `HIGH`
