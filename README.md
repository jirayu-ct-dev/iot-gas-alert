## 2. การต่อวงจร (Wiring Diagram)

⚠️ **ข้อควรระวัง:** 1. **Relay และ MQ-2 ต้องใช้ไฟ 5V (Vin)** ห้ามต่อเข้ากับ 3.3V 
2. **พัดลม 12V ต้องใช้แหล่งจ่ายไฟแยก** ห้ามดึงไฟจากบอร์ด ESP8266

### 2.1 การต่อสายเข้าบอร์ด ESP8266

| อุปกรณ์ | ขาของอุปกรณ์ | ต่อเข้ากับ ESP8266 (NodeMCU) |
| :--- | :--- | :--- |
| **MQ-2 Sensor** | VCC | **Vin** (5V) |
| | GND | **GND** |
| | A0 (Analog) | **A0** |
| **LCD I2C** | VCC | **Vin** (5V) |
| | GND | **GND** |
| | SDA | **D2** (GPIO 4) |
| | SCL | **D1** (GPIO 5) |
| **Relay Module** | VCC | **Vin** (5V) |
| | GND | **GND** |
| | IN | **D7** (GPIO 13) |
| **Buzzer** | VCC (+) | **3V3** (3.3V) |
| | GND (-) | **GND** |
| | I/O (Signal) | **D6** (GPIO 12) |
| **LED** | ขาบวก (+) | **D5** (GPIO 14) |
| | ขาลบ (-) | **GND** |

### 2.2 การต่อพัดลมเข้ากับ Relay (ด้านไฟแรงสูง)
1. สายไฟบวก (+) จาก Adapter 12V --> เข้าช่อง **COM** ของ Relay
2. สายจากช่อง **NO** (Normally Open) ของ Relay --> เข้าขั้วบวก (+) ของพัดลม
3. สายไฟลบ (-) จาก Adapter 12V --> ต่อตรงเข้าขั้วลบ (-) ของพัดลม

## 3. การตั้งค่า Blynk (Configuration)

### ขั้นตอนที่ 1: สร้าง Template (บนเว็บ blynk.cloud)
1. ไปที่เมนู **Templates** -> กด **+ New Template**
2. **Name:** ตั้งชื่อว่า `Gas Detector`
3. **Hardware:** เลือก `ESP8266`
4. **Connection Type:** เลือก `WiFi`

### ขั้นตอนที่ 2: ตั้งค่า Datastreams (ตัวแปร)
ไปที่แท็บ **Datastreams** แล้วกด **+ New Datastream** -> **Virtual Pin** ให้ครบตามตารางนี้:

| ชื่อ (Name) | Pin | Data Type | Min/Max | หมายเหตุ |
| :--- | :--- | :--- | :--- | :--- |
| **Gas Value** | **V0** | Integer | 0 - 1024 | ค่าที่อ่านได้จากเซนเซอร์ |
| **Sensitivity Level** | **V1** | Integer | 1 - 3 | เลือกระดับความไว (Low/Mid/High) |
| **Manual Fan** | **V2** | Integer | 0 - 1 | ปุ่มทดสอบพัดลม (0=ปิด, 1=เปิด) |
| **LCD Status** | **V3** | String | - | ข้อความสถานะส่งเข้าจอแอป |

### ขั้นตอนที่ 3: สร้างหน้าจอควบคุม (บนแอปมือถือ Blynk IoT)
1. เปิดแอปในมือถือ เลือก Template ที่สร้างไว้
2. เพิ่ม Widget ดังนี้:
   * **Gauge (เกจวัด):** เลือก Datastream `Gas Value (V0)`
   * **Segmented Switch:** เลือก Datastream `Sensitivity Level (V1)`
     * ตั้งค่า: 1:Low, 2:Mid, 3:High
   * **Button/Switch:** เลือก Datastream `Manual Fan (V2)`
   * **LCD:** เลือก Datastream `LCD Status (V3)` (โหมด Advanced)

### ขั้นตอนที่ 4: ตั้งค่าการแจ้งเตือน (Events)
1. ในเว็บ Console ไปที่แท็บ **Events**
2. สร้าง Event ใหม่ชื่อ `gas_alert`
3. Type: **Critical**
4. เปิด **Push to mobile devices**

## 5. คู่มือการใช้งาน (User Guide)

### 5.1 โหมดปกติ (Auto Mode)
ระบบจะทำงานอัตโนมัติตามค่าความไวที่ตั้งไว้:
* **สถานะปกติ (Safe):** ไฟเขียว/จอขึ้น Safe พัดลมปิด
* **สถานะอันตราย (Danger):** * เมื่อค่าแก๊สสูงกว่ากำหนด -> ไฟแดงติด, เสียงดัง, พัดลมทำงาน, แจ้งเตือนเข้ามือถือ
* **สถานะระบายควัน (Clearing):**
  * เมื่อค่าแก๊สลดลงแล้ว -> พัดลมจะยัง **หมุนต่ออีก 10 วินาที** เพื่อระบายควันที่ตกค้างจนหมด แล้วจึงดับเอง

### 5.2 การปรับความไว (Sensitivity Setting)
กดปุ่ม **Segmented Switch** บนแอปเพื่อเลือกระดับ:
* **Low:** แจ้งเตือนเมื่อค่าเกิน **300** (ไวมาก เหมาะกับห้องปิด)
* **Mid:** แจ้งเตือนเมื่อค่าเกิน **500** (ค่ามาตรฐาน)
* **High:** แจ้งเตือนเมื่อค่าเกิน **800** (สำหรับพื้นที่ที่มีควันบ้างอยู่แล้ว)

### 5.3 โหมดทดสอบ/ระบายอากาศ (Manual Mode)
* กดปุ่ม **Manual Fan** ในแอปเพื่อ **"บังคับเปิดพัดลม"** ทันที
* ใช้สำหรับทดสอบระบบ หรือต้องการระบายอากาศในห้องโดยที่แก๊สยังไม่รั่ว
* ข้อความบนจอจะขึ้นว่า `Mode: Manual ON`

## 6. การแก้ปัญหาเบื้องต้น (Troubleshooting)

### Q1: พัดลมเปิดแล้วไม่ยอมดับ (Relay ค้าง)
* **สาเหตุ:** ไฟเลี้ยง Relay ไม่พอ หรือแรงดัน Logic 3.3V ตัด Relay 5V ไม่ขาด
* **วิธีแก้:** เช็คว่าโค้ดใช้ฟังก์ชัน `pinMode(RELAY_PIN, INPUT);` ในการสั่งปิดหรือไม่ (โค้ดล่าสุดแก้ปัญหานี้แล้ว) และต้องเสียบไฟ Relay ที่ขา **Vin** เท่านั้น

### Q2: หน้าจอ LCD วูบ หรือตัวหนังสือจางเมื่อพัดลมทำงาน
* **สาเหตุ:** ไฟไม่พอจ่าย (ไฟตก) เนื่องจากเซนเซอร์และ Relay กินกระแสสูง
* **วิธีแก้:** เปลี่ยนแหล่งจ่ายไฟจากเสียบสาย USB คอมพิวเตอร์ เป็น **Adapter มือถือ (5V 2A)** เสียบเข้าที่ช่อง Micro USB ของบอร์ด

### Q3: หน้าจอ LCD ไฟติดแต่ไม่มีตัวหนังสือ
* **วิธีแก้:** ด้านหลังจอ LCD จะมีตัวปรับสีฟ้า (Potentiometer) ให้เอาไขควงหมุนปรับความเข้ม (Contrast) จนกว่าตัวหนังสือจะปรากฏ
